## How to use this repo

1. Read a guide.
2. Open the matching folder and run the notebook top to bottom. Each one starts with a diagram.
3. Try the "Try it yourself" idea at the end of the guide.

You can also follow along with the [interactive slides](https://d-hackmt.github.io/langgraph-life/).
